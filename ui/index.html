      Account

      The password is kept in your system's keychain (Keychain on Mac, Credential Manager on Windows, the keyring on Linux), never in a plain file.

      Audio

      Changes apply right away, even during a call. Plugged in a headset? Reopen this screen to see it. Closing the window keeps the phone running in the tray / menu bar; quit from there.

      Calls

      Intercom calls are ones your PBX marks for auto-answer, like FreePBX's *80 paging. Forwarding sends callers on to the other number without ringing here. Extension status lights appear on contacts whose number is an extension (2 to 6 digits).

      Shortcuts and startup

      Write keys like CommandOrControl+Alt+Shift+A (Command on Mac, Ctrl elsewhere). Links like tel:5551234 and sip:1002@pbx open here and dial.

      Updates

      Checks for new versions at startup and every few hours.

      Troubleshooting

      The app keeps a log of the current session. If something goes wrong, make a short call, then click below and drag the sip.log file into a message.
